# Pharmacy Management System

The **Pharmacy Management System** is a web-based business management application developed using **PHP, CodeIgniter, and MySQL** to streamline and manage the day-to-day operations of a pharmacy.

The system provides an integrated platform for managing medicines, inventory, purchasing, sales, suppliers, accounting, and staff. It helps pharmacy administrators maintain organized records, monitor stock and transactions, track purchase and sales activities, manage supplier payments, and review overall financial performance through a centralized dashboard.

The application is designed with a modular structure, making core pharmacy operations easier to manage while providing administrators with a clear overview of inventory, sales, purchases, outstanding payments, and staff information.
